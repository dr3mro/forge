Getting started

Install Forge

Forge runs on macOS and Linux. Put Bash 4+ on your PATH. Use forge doctor to check CMake, a C++ compiler, Ninja, Git, jq, Python with tomllib, Conan 2, and ShellCheck.

Install with curl

The installer fetches the official Forge repository, configures Bash and Zsh completions, and adds ~/.local/bin to PATH when needed. Open a new shell and run forge doctor.

Shell
curl -fsSL https://raw.githubusercontent.com/dr3mro/forge/refs/heads/main/install.sh | sh

Choose another source

From a local checkout or unpacked archive, pass its directory to --source. The same option accepts another Git repository URL.

sh install.sh --source .

Usage guide

Workflows

Scaffold or adopt a project

new creates a directory. init works in the current directory. Each supplied metadata flag skips its prompt. Use --defaults for scripts. Scaffolds provide CMake presets, tests, and Zed and VS Code tasks.

forge new --name hello --git
forge init --lib --name widget --defaults

Build, run, and test

Build debug or release presets. Forward application arguments after --. Run CTest with a filter or sanitizer. Use the debug target option to create a stable LLDB launch path.

forge build --release
forge run --build --release --bin hello -- --version
forge test --sanitize address
forge build --debug-target hello

Declare dependencies

Accepting sync after a Conan add refreshes the workspace lock. Use vcpkg for ports and features, full Git SHAs for FetchContent, or relative paths for local CMake libraries. Edit Conan ref and conan_options in TOML. vcpkg supports features, default_features, and exact versions with a workspace baseline.

forge add fmt/12.1.0 --conan
forge add zlib --vcpkg --cmake-target ZLIB::ZLIB
forge deps status --format json

Grow a workspace

Each member gets its own manifest. Generated libraries link into the parent targets. C++ library scaffolds include a class with defaulted copy and move operations and a virtual destructor. The namespace defaults to the root application project name for generated members.

forge generate lib math --namespace acme::numeric
forge generate lib codec --c --static
forge generate lib plugin --shared
forge generate bin worker
forge remove math --lib

Reconcile generated files

Preview changes before applying a three-way merge. Forge records conflicts as proposals. Dependency removal updates manifests and syncs CMake. A detached library keeps its source files.

forge sync --check
forge sync --diff
forge sync --apply --yes
forge remove fmt

Release and automate

A successful numeric Git tag updates the app version when the generated hook is installed. CMake uses the numeric version and the default app displays the full tag. New projects include GitHub Actions for Debug and Release on Windows, Linux, and macOS. Linux exports a cached dependency OCI image and builds a separate project image from that exact image. Check formatting, export metadata, or build API docs with Doxygen.

git tag v1.2.3
forge build && forge run -- --version
forge workflow init
forge fmt --check
forge metadata --format json
forge docs

Add a Git dependency with FetchContent

forge add fmt_git --source git --url https://github.com/fmtlib/fmt.git --tag 12.0.0 --cmake-target fmt::fmt
forge build

fmt_git is the dependency name in Forge.toml. Use the CMake target exported by the upstream project. Forge resolves the tag to a full commit SHA. Sync generates the FetchContent rules. You can also use --branch NAME or --sha SHA.

If your target already has a nonempty links list, add "fmt_git" to it and run forge sync --apply before building. With Bash or Zsh completion loaded, type forge add fmt_git --source g and press Tab. After entering the source, URL, or revision, type a space and press Tab for the next Git option.

Customize generated CMake

Dependencies use modules such as cmake/deps/fmt.cmake. Set defaults in the [cmake.variables] table in Forge.toml; Forge renders them into cmake/ProjectOptionsUser.cmake. The user-owned cmake/user.cmake loads after those defaults and before dependencies and targets; sync never rewrites it and moves an older root user.cmake on the next apply. Cargo-style Clang diagnostics live in the managed cmake/Diagnostics.cmake; set FORGE_CLANG_DIAGNOSTICS to OFF in cmake/user.cmake to opt out. On macOS, cmake/CodeSign.cmake signs executables and shared libraries with the root entitlements.plist (user-owned, with get-task-allow so LLDB and leaks can attach). Set FORGE_CODESIGN_IDENTITY to a keychain identity or an empty string to change or disable signing. clangd and clang-tidy can consume the generated compilation database.

[cmake.variables]
FORGE_CODESIGN_IDENTITY = "adhoc"
FORGE_CODESIGN_ENTITLEMENTS = "entitlements.plist"
CMAKE_CXX_FLAGS_DEBUG = "-O0 -g"
